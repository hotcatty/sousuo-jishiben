# 搜搜记事本

在小红书上搜东西时用的浏览器记事本。带着目的进来，把有用的帖子、评论、截图收进侧栏，整理成板块，再按建议词继续搜。

目前做成 Chrome 扩展，深度适配 [小红书](https://www.xiaohongshu.com/)。尚未上架 Chrome 网上应用店，从本仓库的 Release 下载 zip 即可本地加载。

## 功能

### 专注模式

打开小红书时先问你这次来搜什么。之后会尽量把你留在搜索里：推荐首页会拦一下，点进和目的不太相关的笔记时会提醒你拉回来。

不想被打断时，关掉专注模式，或进站时选随便逛逛，插件就不会拦。

### 辅助收集与快速整理

在笔记里一键把帖子、评论、截图收进侧栏收集箱。攒了一批之后点「快速整理」，按主题拆成板块和卡片（比如路线、美食、住宿），并给出下一步能直接搜的短词。

原文会留在收集箱里，整理结果是另写的卡片。你改过的卡片不会被下次整理覆盖。

## 安装

需要 Chrome（或同内核的 Chromium 浏览器）。

1. 打开 [Releases](https://github.com/hotcatty/sousuo-jishiben/releases/latest)，下载最新的 `sousuo-jishiben-*.zip`。
2. 解压到一个你会留下来的文件夹。Chrome 会一直读这个目录，解压完不要删。
3. 地址栏打开 `chrome://extensions`，打开右上角 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选中刚才那个文件夹（能直接看到 `manifest.json` 的那一层）。
5. 打开 [小红书](https://www.xiaohongshu.com/)，点浏览器工具栏里的「搜搜记事本」图标，侧栏就会出来。

不要把 zip 直接拖进扩展页，未上架的扩展只能用「加载已解压的扩展程序」。

如果工具栏上看不到图标：点扩展拼图按钮，把「搜搜记事本」固定到工具栏。

## 更新

1. 再下一个新的 zip，解压覆盖原来的文件夹。如果解压到了新目录，先在扩展页移除旧的，再重新加载。
2. 回到 `chrome://extensions`，在「搜搜记事本」卡片上点 **重新加载**。
3. 刷新小红书页面。只刷新网页不够，扩展脚本不会自动换成新版本。

现在是手动加载的未打包扩展，Chrome 不会自动升级，也不会弹更新提醒。想在发新版本时收到邮件：打开本仓库 → 右上角 **Watch** → **Custom** → 勾选 **Releases**。

## 从源码加载

克隆本仓库后，也可以直接把仓库根目录当作未打包扩展加载（同样要能看到 `manifest.json`）。

打包成 zip：

```bash
bash scripts/pack.sh
```

生成文件在 `dist/sousuo-jishiben-<version>.zip`。
